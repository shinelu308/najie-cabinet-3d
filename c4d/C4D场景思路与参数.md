### 2.5 建模手法与硬参数（这一节决定「工业感」）

| 手法 | 操作路径 | 关键参数 |
|---|---|---|
| 硬表面起步 | 立方体 → 右键「转为可编辑对象」(C) → 环切 (K/KL) → 挤出 (D) | 板件一律建**有厚度的实体**，不做单面片 |
| ⭐ 倒角（最重要） | 多边形模式选中边 → 右键「倒角」/ 用倒角工具 (MS) | **偏移 1.5–3 mm、细分 2–3、圆角类型=圆角**；全场景边都倒角，金属高光才有亮边，否则像纸模 |
| ⭐ 母排/电缆 | 贝塞尔样条 → 点右键「**圆角**」(半径 20–40 mm 做折弯) → **扫描 (Sweep)** | 母排截面 **矩形 100×10 mm**（示例）；电缆截面 **圆 φ8~φ60**。比逐段拼面省 90% 工时 |
| 三相阵列 | 克隆器 (Cloner) → 模式=线性 | 方向 Y，步幅 = 相间距离，数量 3 |
| 端子排 | 克隆器 → 线性 | 数量 14 / 步距 12 mm / 3 层 DIN 导轨 |
| 螺栓螺母 | 克隆器 + 实例 | 柜内约 120 颗，全部实例，勿复制 |
| 通风百叶 | 克隆器（窄条）+ 布尔(A 减 B) | 布尔后勾「高质量」，且**先转可编辑再布尔**更稳 |
| 剖切缺口 | 单独建模一块「缺角侧板」 | ⚠️ 不要指望布尔切 1/4 楔形，烂面率极高；剖切版另存一块缺角板切换显示即可 |
| 复用 | 文件 → 实例 / 克隆器「对象」模式 | 高压柜与低压柜共用的骨架、外壳、细节件走实例，省内存 |

**多边形预算**

| 层级 | 目标 | 备注 |
|---|---|---|
| 单柜 | 15–35 万三角面 | 展示级；视口卡就加「显示标签」降级 |
| 全场景 | ≤ 80 万 | Redshift GPU 无压力，视口压力靠显示标签管理 |

## 4. 电气数字模型与工作原理（动画分镜）

### 4.1 一次主接线拓扑（模型必须严格按此连，否则电流会「跳线」）

**高压侧（KYN28-12，10 kV）**

```
进线电缆 (YJV-8.7/15kV)
  → 零序 CT / 接地排
  → 电缆室铜排接头
  → 电流互感器 CT (A/B/C 各 1)
  → 手车式真空断路器 VCB (合闸点)
  → 隔离静触头盒
  → 接地开关 (合闸时断开)
  → 母线穿墙套管
  → 母线室主母排 A/B/C
  → 分支母排 → 出线电缆 → 变压器
```

**低压侧（GGD，0.4 kV）**

```
进线 (0.4 kV)
  → 智能断路器 (ACB/MCCB)
  → 主母排 A/B/C + N
  → 分支断路器 / 接触器 / 热继电器
  → 端子排 / PLC 模块
  → 出线电缆 (YJV) → 负载
```

**三相色标（中国惯例，与 three.js 版一致）**

| 相 | 色 | Hex |
|---|---|---|
| A | 黄 | `#E0B400` |
| B | 绿 | `#1E9C46` |
| C | 红 | `#D13B2C` |
| N | 淡蓝 | `#4A90D9` |
| PE | 黄绿双色 | `#2E9E5B` + 黄条纹 |

### 4.2 分镜表（450 帧）

| 时间 | 帧 | 画面内容 | 技术动作 |
|---|---|---|---|
| 0.0 – 1.5 s | 0 – 45 | 双柜闭合，正面 0° 起转，主光扫过外壳 | 相机 R.Y 0→36°；门闭合 |
| 1.5 – 4.0 s | 45 – 120 | 外壳渐隐为玻璃质感，内部结构浮现 | `CTL_ENC_OPACITY` 1 → 0.18（材质 Opacity 打关键帧，缓入缓出） |
| 4.0 – 5.5 s | 120 – 165 | 手车摇出 → 再摇入（**分→合**动作节拍） | `CTL_CAR_INOUT` 位移 X +150 mm 再回 0；底盘把手旋转 90° |
| 5.5 – 7.5 s | 165 – 225 | 合闸：进线→CT→VCB→套管→母排 逐级点亮 | 三相流光的 `样条效果器·偏移` 依次启动（时间差 8 帧） |
| 7.5 – 11.0 s | 225 – 330 | 三相主回路全亮 + 支路分流到低压柜；灭弧室发蓝紫光 | 全粒子流循环流动 + Bloom 强度提升 |
| 11.0 – 13.5 s | 330 – 405 | 相机推近柜内（推镜），仪表盘数字与参数标注淡入 | `CAM_CLOSE` 接管或 PIVOT 半径 5000 → 2600 mm |
| 13.5 – 15.0 s | 405 – 450 | 外壳回位、回到正面、品牌收尾；末帧 = 首帧 | 透明度回 1；相机回到 360° |

> **提气点**：4.0–5.5 s 的手车摇出/摇入是全片唯一的「机械动作」，比纯流光更有说服力，别省。

### 4.3 相机路径参数

| 项 | 值 |
|---|---|
| 焦距 | **65 mm**（长焦，透视变形小，产品展示惯用） |
| 传感器 | 36 mm 全画幅 |
| 相机高度 | **1250 mm**（略高于柜体中心 1100 mm） |
| 注视点 | (0, 1080, 0)，俯角 ≈ **1.95°** |
| 绕行半径 | **5000 mm**（水平视野 ≈ 2772 mm，1700 mm 双柜占 61%，留白合适） |
| 光圈 | f/8（2.2 m 高柜体保持全清晰），特写镜头切 f/2.8 |
| 推镜段 | 半径 5000 → 2600 mm，注视点 y 1080 → 1400 mm（看向断路器） |
| 竖版（1080×1920） | 焦距改 85 mm 或半径 +2000 mm |

> ⭐ **转盘实现推荐「相机绕行」**而非「场景自转」：电流流光的空间位置不变、地面接触阴影稳定、环境反射随视角正确变化；15 s 一圈观感也最像产品片。
> 且**用 Null 层级做（PIVOT 转 Y + TILT 转 X + 相机子级）**，不用「对齐曲线 / 目标」标签 —— 标签方案在运动图形里偶发朝向翻转，Null 层级任何版本都不会出错。
> 若一定用标签：相机 + 圆形样条 + **对齐曲线标签** + **目标标签**指向中心 Null；两者冲突时把目标标签的**优先级调低**，或改用**约束标签**。

## 5. 电流流动 —— 三套实现方案（可叠加）

### 方案 A｜克隆器 + 样条效果器（推荐主用，最直观）

| 步骤 | 操作路径 | 参数 |
|---|---|---|
| 1 | 画电流路径：`41_PATH` 里的样条 | 贝塞尔，挂在母排/电缆正中心，略偏内 3 mm 防 Z-fighting |
| 2 | 建粒子：球体 | 半径 **12–18 mm**，段数 12/8；或胶囊体做「电子流」质感 |
| 3 | 材质 | RS 标准材质 → Emission Color = 相色，**Amount 40–120**；关闭「投影」与「接收阴影」 |
| 4 | 克隆器 | 模式 = **对象** → 拖入样条；分布 = 步幅 **60 mm**（或数量 24） |
| 5 | 样条效果器 | 拖入同一条样条；动画其 **偏移 (Offset)** 参数 0 → 100% |
| 6 | 循环 | 用时间线「循环」或把 Offset 打「0→100%」并设**线性切线**，重复 3 次 |
| 7 | 拖尾 | RS 渲染/相机 → **Motion Blur** 开，Shutter Speed 0.5–1.0，Sub-Frames 4 |

> ⚠️ 「样条效果器」的偏移参数**具体标签名随版本略有差异**（待核实）—— 若找不到，直接用**方案 B**，它 100% 存在。

### 方案 B｜扫描「结束生长」动画（最保险，做「合闸推进」节拍）

| 步骤 | 参数 |
|---|---|
| 1 | 电流路径样条 + 发光截面（圆 φ20 mm） → **扫描 (Sweep)** |
| 2 | 扫描 → **开始生长 / 结束生长 (Start / End Growth) 0→100%** 打关键帧 |
| 3 | 动画「结束生长」0→100% → 一段发光管沿路径推进，天然形成「电流来了」的叙事 |
| 4 | 叠一层「开始生长」延迟 6 帧，就得到**一段固定长度的光带在跑** |

### 方案 C｜材质发射条纹滚动（最省对象，适合常亮底噪）

| 步骤 | 参数 |
|---|---|
| 1 | 母排/电缆材质 → Emission 通道接 **Redshift 渐变 (Ramp) 或 颜色层 (Color Layer)** |
| 2 | 映射坐标 = **UVW 或 对象坐标**，取 U 方向（沿长度） |
| 3 | 用 **时间节点 / 噪波动画速率** 让条纹滚动；或接「数学节点」做周期位移 |
| 4 | Emission Amount 峰值 60，谷值 0 → 明暗相间的流动包裹整条母排 |

> **组合建议**：C 做常亮底噪（整条母排微微流动）→ A 做三相主回路粒子流 → B 做合闸瞬间的推进光带。三层叠加就是参考图那种「内部在活」的观感。

### 电流速度参考

| 场景 | 速度 | 视觉结果 |
|---|---|---|
| 常速 | 粒子走完主回路 1.2–1.8 s | 稳定、可读，适合长时间展示 |
| 合闸瞬间 | 0.5 s 冲完全程 | 有冲击力，配 Bloom 峰值 |
| 分闸瞬间 | 粒子瞬间熄灭 + Bloom 塌陷 | 明确「断电」信号，0.2 s 内完成 |

### ⭐ 透明外壳的三个关键点（这条是参考图观感的命门）

1. **Thin-Walled 必须勾** —— 不勾就是实心玻璃砖，内部全被折射吞掉。
2. **Opacity 0.15–0.25，不要更高** —— 高了变成「白塑料板」，Bloom 一开就糊成一片。
3. **玻璃感来自描边和框架，不是板面本身** —— 给外壳加 **Fresnel 驱动的边缘发光**（RS 材质 Emission 接 Fresnel 节点，边缘 Amount 30），或单独用细样条扫出白色棱边（`#9CD0FF`）。板面几乎不可见才对。
   > 这是之前在 three.js 版上试了四版才悟到的结论，C4D 里同样成立。

## 8. 渲染输出设置

### 8.1 Redshift 渲染设置

| 面板 | 参数 | 值 |
|---|---|---|
| 输出 | 分辨率 | 1920×1080（竖版 1080×1920） |
| 输出 | 帧范围 | 0–450 |
| 采样 | Unified Sampling | Min Samples **16** / Max Samples **1024**（最终）、预览 256 |
| 采样 | Adaptive Error Threshold | **0.008 – 0.012** |
| 降噪 | Denoiser | OptiX 开启（预览也开，出图快一倍） |
| 全局光照 | Primary GI Engine | Brute Force（质量）或 Irradiance Cache（速度） |
| 全局光照 | Secondary GI Engine | Irradiance Point Cloud |
| 光线深度 | Total | 24 |
| 光线深度 | Diffuse / Reflection / Refraction | **4 / 6 / 8** |
| ⭐ 光线深度 | Refraction ≥ 8 | **必须**，否则透明外壳里看不到内部结构 |
| 运动模糊 | Motion Blur | 开，Shutter 0.5，Sub-Frames 4 |
| Clamp | Max Secondary | 200（防萤火虫），其余关 |
| 输出格式 | 图像 | PNG 16-bit (sRGB) 或 EXR 半浮点 |

### 8.2 发光与 Bloom（RS 相机 → Post FX）

| 参数 | 值 | 说明 |
|---|---|---|
| Bloom 开关 | 开 | RS 相机 → 后期效果 → 泛光 |
| **阈值 (Threshold)** | **≈ 0.85** | ⭐ **必须卡在「发光体亮度」与「外壳白架亮度」之间**。调到 0.7 会把整个柜体点着，糊成一团蓝白雾 |
| 强度 | 0.3 | 宁淡勿浓 |
| 半径 | 12 | 大半径给氛围，小半径给霓虹感 |
| Streak / Glare | 可选 | 只在「合闸瞬间」帧段开，做冲击感 |

> 阈值 > 强度：**发光体与主体的亮度差才是关键参数，不是强度**。这条是在 three.js 版上把阈值从 0.72 提到 0.93 才修好的经验，RS 里同理。

### 8.3 Physical 渲染器备选（没装 Redshift 时）

| 参数 | 值 |
|---|---|
| 采样质量 | 高，每像素最大采样 512 |
| 全局光照 | 开启，漫反射深度 3，IR 预计算 + QMC |
| 环境吸收 (AO) | 开，最小 30% / 最大 100%，光线 64 |
| 景深 | 仅特写镜头开（f/2.8） |
| 说明 | 无 Redshift 就没有硬件降噪，出图时间约 5–10 倍，建议 1280×720 预览 |
