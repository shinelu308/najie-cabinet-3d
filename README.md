# 上海纳杰电气 · 高低压开关柜三维数字模型

针对 NJA（上海纳杰电气）高低压开关柜的三维数字化验证工程。

## 这一版做了什么

在一个柜体骨架上，长出了完整的**柜体板件 + 柜内一次回路 + 接线 + 安全净距校核 + 爆炸分解**：

| 分区 | 内容 |
|---|---|
| 柜体结构 | 骨架（C 型钢）+ 侧板 + 隔板（母线室 / 断路器室 / 电缆室）+ 安装板（带冲孔阵列）+ 安装梁 + 前门（观察窗 + 门边螺栓列）+ 后下门（通风百叶）+ 后上封板 |
| 母线室（后上） | 主母排 A/B/C 三相铜排（相色热缩套管 + 接头压板 + 端部黑热缩）+ 支撑绝缘子与托板 |
| 断路器室（前中） | 手车式断路器（机构箱 + 底盘车 + 三相极柱 + 铜触臂 + 脱扣单元 / 操作手柄 / 铭牌 / 指示灯）+ 静触头盒 ×3（带支撑绝缘子）+ 手车导轨 |
| 电缆室（后下） | 电流互感器 ×3 + 电力电缆（相色热缩头 + 压接铜鼻 + 抱箍）+ 模块化端子排（2 × 8 端子块 + DIN 导轨 + 短接铜排）+ 接地母排 |
| 仪表室（前上） | 二次仪表 ×3（表圈 + 指针） |
| 安全净距 | 柜前维护通道包络 + 手车抽出空间包络 + 母排相间净距校核 |
| **爆炸分解** | 16 个零件组按登记的"分解方向 + 抛出距离"散开，引导虚线 + 零件标签，相机自动重定距 |

**为什么从骨架起步**：骨架是柜体唯一的结构母体单元 —— 侧板、隔板、门板、安装梁，以及所有元器件最终都挂在它上面。而且它天然参数化：**一个 C 型钢截面函数，就能生成任意尺寸的柜架**。

## 爆炸分解（本版新增）

不重建几何，纯变换 —— 每个零件组在登记时给一个**分解方向 `dir` + 满爆抛出距离 `t`**，实际位移取 `dir × t × e`（`e` 为爆炸进度 0~1）。

| 零件组 | 分解方向 | 抛出距离 | 零件组 | 分解方向 | 抛出距离 |
|---|---|---|---|---|---|
| 顶板 | +Y | 720 mm | 前柜门 | −X / +Z | 1050 mm |
| 底板 | −Y | 580 mm | 前后柜门 | +X / −Z | 920 mm |
| 侧板 ×2 | ±X | 950 mm | 母排 | −X / +Y / +Z | 800 mm |
| 隔板 | −Z | 740 mm | 断路器 | +X / +Z | 780 mm |
| 安装板 | −Z | 860 mm | 互感器 | −Y / −Z | 600 mm |
| 安装梁 | +Y / +Z | 500 mm | 电缆 | +X / −Z | 580 mm |
| 仪表室 | +Z | 660 mm | 端子排 | +X / −Y | 520 mm |

配套三个机制：

1. **引导虚线** —— `LineDashedMaterial`，起点锁在装配态位置、终点跟零件走，画出抛出轨迹；
2. **相机自动重定距** —— 分解后整体包络变大，`camDist()` 按 `1 + e × 0.70` 放大取景半径，同时把注视点从 `0.46H` 抬到 `0.56H`，构图不会"上重下空"；只重算距离，保留用户的旋转角度；
3. **标签错位** —— 每个零件额外的标签微调量 + 每帧屏幕空间的贪心下推（见下节陷阱）。

## 观感怎么来的（不是靠贴图）

所有质感都来自几何与光照，没有一张纹理贴图：

| 手段 | 作用 |
|---|---|
| `PMREMGenerator + RoomEnvironment` | 金属 / 镀锌面必须有环境反射，否则是"死灰" |
| `EdgesGeometry` 描边 | CAD 观感的关键 —— 金属棱线才"立"得起来 |
| 折边钣金 `foldedPanel()` | 平板 + 四边折边，纯 Box 一眼就是"积木" |
| 通风百叶 `louver()` | 暗色衬板 + n 片倾斜叶片，钣金味立刻出来 |
| `InstancedMesh` 螺栓 / 冲孔阵列 | 几十颗只占一个 draw call，统计时按 `count` 计 |
| 竖向渐变背景 `gradientBG()` | 产品摄影棚式背景，去掉纯色的"塑料感" |

## 安全净距校核（12 kV 基准）

模型内置了可量化的校核，不是"看起来像"：

| 校核项 | 实测 | 要求 | 结论 |
|---|---|---|---|
| 柜前维护通道 | 800 mm | ≥ 800 mm | ✓ |
| 母排相间净距 | 70 mm | ≥ 100 mm | ⚠ 不足 |

> 母排按 82 mm 中心距、12 mm 排厚排布，净距 70 mm，低于 12 kV 常用的 100 mm 净距基准。
> 这是模型直接暴露出来的**设计问题**，也算"做三维数字模型"相对二维图纸的直接价值 —— 图纸上看不出，模型里一量就知道。
> （基准值以工程设计方确认为准，此处仅作演示。）

## 技术栈

单文件 HTML + three.js（CDN 引入）。所有几何由代码程序化生成，不依赖任何外部模型文件（无 STEP / glTF / OBJ）。

核心函数：

```
cProfile(a, b, t)      →  C 型钢截面轮廓
strut(len, axis)       →  按轴向挤出成型钢，阵列成柜架
axisBox / axisPos      →  轴向无关小工具（同一套写法生成 XY / XZ / ZY 板）
foldedPanel(w, h, t)   →  折边钣金件
louver(w, h, n)        →  通风百叶
boltRow / holeRow      →  InstancedMesh 螺栓 / 冲孔阵列
withEdges(mesh, angle) →  EdgesGeometry 描边
exGroup(dir, t, name)  →  登记一个爆炸分解单元
buildShell()           →  侧板 / 隔板 / 安装板 / 双开柜门（含铰链组与门边螺栓列）
buildComponents()      →  一次元件 / 二次元件 / 电缆 / 手车导轨 / 静触头盒
buildGuards()          →  维护通道与抽出空间包络 + 净距校核标签
applyMotion()          →  门开合角度与手车位移（不重建几何）
applyExplode()         →  爆炸位移 + 引导虚线端点 + 标签 / 尺寸 / 包络联动
buildDims()            →  尺寸标注 + 部件名称标签
CatmullRomCurve3 + TubeGeometry  →  电缆按空间路径扫掠成实体
```

变更柜体尺寸、LOD 或显示分组时，几何全部重新计算，因此不存在"改了尺寸要重新建模"的问题。
门开合、手车摇出、爆炸分解只改变换矩阵、不重建几何，所以拖动滑块是实时的。

## 踩过的坑（留给下次）

1. **`CSS2DRenderer` 不看父级 `visible`** —— 把 `dimGroup.visible = false` 之后，尺寸标注的 DOM 元素照样显示。必须 `traverse()` 逐个把 `CSS2DObject.visible` 一起关掉。
2. **`CSS2DRenderer` 每帧重写 `transform`** —— 所以标签的显隐动画只能用 `opacity`（`body.exploded` 类切换）；而要做屏幕空间避让，只能在 `labelRenderer.render()` **之后**往 `style.transform` 字符串后面追加 `translateY()`。
3. **测量前必须归零** —— 在"已分解"状态下重建（切 LOD / 切板件开关）时，`Box3.setFromObject()` 会把上一轮的抛出位移算进装配坐标，引导线起点整体漂移。
4. **标签列表要惰性刷新** —— `CSS2DObject` 的元素是在首次渲染时才被挂进 DOM 的，`build()` 里立刻 `querySelectorAll` 会拿到空列表；用 `isConnected` 判定缓存是否失效。
5. **透明包络不能一律显示** —— 安全净距包络在装配态是信息、在分解态是噪音，要跟着爆炸进度收起。
