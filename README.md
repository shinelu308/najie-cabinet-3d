# 上海纳杰电气 · 高低压开关柜三维数字模型

针对 NJA（上海纳杰电气）高低压开关柜的三维数字化验证工程。

## 这一版做了什么

在一个柜体骨架上，长出了完整的柜内一次回路与接线：

| 分区 | 内容 |
|---|---|
| 母线室（后上） | 主母排 A/B/C 三相 + 支柱绝缘子 |
| 断路器室（前中） | 手车式断路器：机构箱 + 底盘车 + 三相极柱 + 触头盒 |
| 电缆室（后下） | 电流互感器 ×3 + 电力电缆 + 二次端子排 + 避雷器 + 接地母排 |
| 仪表室（前上） | 二次仪表 ×3 |

**为什么从骨架起步**：骨架是柜体唯一的结构母体单元 —— 顶底板、柜门、隔室、安装梁，以及所有元器件最终都挂在它上面。而且它天然参数化：**一个 C 型钢截面函数，就能生成任意尺寸的柜架**。

## 模型精度（LOD）分级

| LOD | 网格 | 三角面 | 顶点 | 工程含义 |
|---|---|---|---|---|
| 1 外形 | 23 | 744 | 795 | 骨架方柱外廓 + 元器件占位块，用于空间校核与方案排布 |
| 2 工程 | 64 | 4,532 | 5,687 | 真实 C 型钢截面 + 断路器 / 互感器 / 三相母排 / 电缆走向 / 端子排，可装配、可做干涉与维护空间检查 |
| 3 精细 | 109 | 6,084 | 8,293 | 追加二次仪表、避雷器、支柱绝缘子、备用控制电缆、端子分片，可出加工图与装配图 |

三档的差异不只是"好看程度"，而是**工作量与报价的分级依据**。最大档也只有约 6k 三角面 —— 浏览器依旧秒开，这是"最轻量化"路线的直接体现。

## 技术栈

单文件 HTML + three.js（CDN 引入）。所有几何由代码程序化生成，不依赖任何外部模型文件（无 STEP / glTF / OBJ）。

核心函数：

```
cProfile(a, b, t)   →  C 型钢截面轮廓
strut(len, axis)    →  按轴向挤出成型钢，阵列成柜架
buildComponents()   →  一次元件 / 二次元件 / 电缆与接线
CatmullRomCurve3 + TubeGeometry  →  电缆按空间路径扫掠成实体
```

变更柜体尺寸、LOD 或显示分组时，几何全部重新计算，因此不存在"改了尺寸要重新建模"的问题。
