# 上海纳杰电气 · 高低压开关柜三维数字模型

针对 NJA（上海纳杰电气）高低压开关柜的单部件三维建模验证工程。

## 这一版做了什么

只做**一个部件**：柜体骨架（型钢框架）。

选它作为起点的理由：骨架是柜体唯一的结构母体单元 —— 顶底板、前后柜门、隔室、安装梁，以及所有元器件最终都挂在它上面。而且它天然参数化：**一个 C 型钢截面函数，就能生成任意尺寸的柜架**。

## 打开方式

浏览器直接打开 `outputs/najie-rack-3d.html`，无需安装任何依赖、无需构建。

## 交互

| 操作 | 说明 |
|---|---|
| 拖拽 / 滚轮 / 右键拖拽 | 旋转 / 缩放 / 平移 |
| 宽 · 深 · 高 滑块 | 实时重建骨架几何 |
| LOD 1 / 2 / 3 | 切换模型精度等级 |
| 安装梁 · 尺寸标注 · 自动旋转 | 显示开关 |

## 模型精度（LOD）分级

| LOD | 网格 | 三角面 | 顶点 | 工程含义 |
|---|---|---|---|---|
| 1 外形 | 12 | 144 | 288 | 方柱外廓，只表达占位尺寸，用于空间校核与方案排布 |
| 2 工程 | 26 | 728 | 2,184 | 真实 C 型钢截面 + 前后安装梁，可装配、可做干涉与维护空间检查 |
| 3 精细 | 56 | 1,488 | 4,000 | 增加加强竖梁、垫脚板、角部连接件，可出加工图与装配图 |

三档的差异不只是"好看程度"，而是**工作量与报价的分级依据**。整档模型控制在 1.5k 三角面以内，因此浏览器秒开。

## 默认参数

| 项 | 值 |
|---|---|
| 柜体尺寸（W × D × H） | 800 × 1000 × 2200 mm |
| 型钢截面 | C 型钢 45 × 70 × 3.5 mm |
| 参照型号 | KYN28-12 中置式高压开关柜 |

## 技术栈

单文件 HTML + three.js（CDN 引入）。所有几何由代码程序化生成，不依赖任何外部模型文件（无 STEP / glTF / OBJ）。

核心只有三个函数：

```
cProfile(a, b, t)   →  C 型钢截面轮廓
strut(len, axis)    →  按轴向挤出成型钢
build()             →  阵列成完整柜架
```

变更柜体尺寸或 LOD 时，几何全部重新计算，因此不存在"改了尺寸要重新建模"的问题。
