# 上海纳杰电气 · 高低压开关柜三维数字模型

针对 NJA（上海纳杰电气）高低压开关柜的三维数字化验证工程。

## 这一版做了什么

在一个柜体骨架上，长出了完整的**柜体板件 + 柜内一次回路 + 接线 + 安全净距校核**：

| 分区 | 内容 |
|---|---|
| 柜体结构 | 骨架（C 型钢）+ 侧板 + 隔板（母线室 / 断路器室 / 电缆室隔板）+ 前门（带观察窗与把手）+ 后下门 + 后上封板 |
| 母线室（后上） | 主母排 A/B/C 三相 + 支柱绝缘子 |
| 断路器室（前中） | 手车式断路器（机构箱 + 底盘车 + 三相极柱 + 铜触臂）+ 静触头盒 ×3 + 手车导轨 |
| 电缆室（后下） | 电流互感器 ×3 + 电力电缆 + 二次端子排 + 避雷器 + 接地母排 |
| 仪表室（前上） | 二次仪表 ×3 |
| 安全净距 | 柜前维护通道包络 + 手车抽出空间包络 + 母排相间净距校核 |

**为什么从骨架起步**：骨架是柜体唯一的结构母体单元 —— 侧板、隔板、门板、安装梁，以及所有元器件最终都挂在它上面。而且它天然参数化：**一个 C 型钢截面函数，就能生成任意尺寸的柜架**。

## 模型精度（LOD）分级

| LOD | 网格 | 三角面 | 顶点 | 工程含义 |
|---|---|---|---|---|
| 1 外形 | 32 | 908 | 1,091 | 骨架方柱外廓 + 柜体板件与元器件**半透明占位块**，仅用于空间校核与方案排布，不可出图 |
| 2 工程 | 83 | 4,924 | 6,379 | 真实 C 型钢截面 + 板件 + 手车式断路器（含触臂）/ 静触头盒 / 手车导轨 / 互感器 / 三相母排 / 电缆走向 / 端子排，可装配、可做带电净距与维护空间校核 |
| 3 精细 | 128 | 6,584 | 9,141 | 追加二次仪表、避雷器、支柱绝缘子、备用控制电缆、端子分片、柜底安装脚与起吊吊环，可出加工图与装配图 |

三档的差异不只是"好看程度"，而是**工作量与报价的分级依据**。最大档也只有约 6.6k 三角面 —— 浏览器依旧秒开，这是"最轻量化"路线的直接体现。

## 安全净距校核（12 kV 基准）

模型内置了可量化的校核，不是"看起来像"：

| 校核项 | 实测 | 要求 | 结论 |
|---|---|---|---|
| 柜前维护通道 | 800 mm | ≥ 800 mm | ✓ |
| 母排相间净距 | 70 mm | ≥ 100 mm | ⚠ 不足 |

> 母排按 82 mm 中心距、12 mm 排厚排布，净距 70 mm，低于 12 kV 常用的 100 mm 净距基准。
> 这是模型直接暴露出来的**设计问题**，也算"做三维数字模型"相对二维图纸的直接价值 —— 图纸上看不出，模型里一量就知道。
> （基准值以工程设计方确认为准，此处仅作演示。）

## 技术栈

单文件 HTML + three.js（CDN 引入）。所有几何由代码程序化生成，不依赖任何外部模型文件（无 STEP / glTF / OBJ）。

核心函数：

```
cProfile(a, b, t)   →  C 型钢截面轮廓
strut(len, axis)    →  按轴向挤出成型钢，阵列成柜架
buildShell()        →  侧板 / 三层隔板 / 双开柜门（含铰链组）
buildComponents()   →  一次元件 / 二次元件 / 电缆 / 手车导轨 / 静触头盒
buildGuards()       →  维护通道与抽出空间包络 + 净距校核标签
applyMotion()       →  门开合角度与手车位移（不重建几何）
buildDims()         →  尺寸标注 + 部件名称标签
CatmullRomCurve3 + TubeGeometry  →  电缆按空间路径扫掠成实体
```

变更柜体尺寸、LOD 或显示分组时，几何全部重新计算，因此不存在"改了尺寸要重新建模"的问题。
门开合与手车摇出只改变换矩阵、不重建几何，所以拖动滑块是实时的。
