# 纳杰电气 · 高低压开关柜三维数字孪生

上海纳杰电气 KYN28-12（高压进线柜）+ GGD（低压出线柜）的交互式三维数字孪生演示。
柜体按 800×1000×2200 mm 工程尺寸在 Blender 中完整建模，导出 glTF 后在浏览器里实时渲染。

**在线演示**：https://shinelu308.github.io/najie-cabinet-3d/

---

## 能做什么

| 功能 | 说明 |
|---|---|
| 双皮肤 | 深色「科技风」/ 浅色「工程图」，背景·雾·地面·网格·灯光·曝光整体联动 |
| 柜门开合 | 高压柜门绕真实铰链轴刚性旋转 0°↔90°，开门后自动半透明，不遮挡柜内元件 |
| 分解视图 | 柜壳与门框保持固定，内部元件沿法向抽出，可调分解度 |
| 剖切视图 | 隐藏前半侧板，直视柜内布置 |
| 通电运行 | 母排按相序（L1 黄 / L2 绿 / L3 红 / N 蓝）跑流动光带，导线带电辉光，指示灯脉动，右侧同步刷新「运行状态」HUD |
| 元件拾取 | 点击任意元件弹出信息卡（类别 / 名称 / 参数 / 说明），内置 25+ 条元件知识库 |
| 标注引线 | 一键显示工程标注：主母排、真空断路器、互感器、框架断路器、塑壳断路器、端子排、电缆桥架等 |
| 分区聚焦 | 高压柜 / 低压柜 / 全柜 一键飞向 |

## 目录结构

```
index.html              单页应用（three.js + importmap，无需构建）
assets/nja-cabinet.glb  模型（约 6.7 MB，479 个网格 / 44 个材质）
vendor/three/           three.js 运行时（本地化，离线可用）
serve.js                本地预览用的零依赖静态服务器
```

## 本地预览

```bash
node serve.js 8321
# 打开 http://127.0.0.1:8321/
```

> `serve.js` 带完整 MIME 表——`.js` 必须是 `text/javascript`、`.glb` 必须是
> `model/gltf-binary`，否则 ES Module 与模型都加载不了。

## 实现要点（踩过的坑）

1. **glTF 会把 pivot 层级展平**——柜门的旋转不能沿用 Blender 里的变换，
   必须在运行时用门的 `boundingBox` + `matrixWorld` 反推铰链轴与真实门宽。
2. **角度基准会因轴变换改变**——Blender 里建模姿态是 103°，经 glTF 的 Y-up 变换后
   等效 77°，靠实测反算而不要硬编码。
3. **glTF 材质默认带 `transparent: true`**（即使 `opacity = 1`），会让渲染排序错乱；
   进场先归一化，做半透明时**必须保留 `depthWrite = true`**，否则门会变成"幽灵板"。
4. **电流流动的实现**：沿母排长轴生成 `TubeGeometry`，贴一张 Canvas 生成的
   虚线条纹并用 `texture.offset.x` 逐帧滚动 + 加色混合；同时让母排材质
   `emissive` 按相序微亮，避免加色混合把相位色调成白色。
